# Privacy

Outlook Style for Thunderbird and Outlook Style Companion operate locally and
do not collect, retain, sell, or transmit personal data.

The Companion observes and styles Thunderbird's own message-reader, compose,
calendar, attendee, reminder, and Today-pane interfaces so it can provide the
documented features. This can place message, contact, attendee, and calendar
content in the same privileged Thunderbird process as the Companion, but the
add-on does not copy that content into its own storage or send it elsewhere.

The packages contain no telemetry, analytics, advertising, remote code, network
client, or external asset loading. They request no WebExtension mail, calendar,
address-book, host, or optional permissions. Thunderbird and configured account
providers continue to make their normal network requests independently of these
add-ons.

Removing both add-ons removes their code and UI behavior. They do not create a
separate user-data database. Thunderbird may retain its own preferences, logs,
and account data according to Thunderbird's policies and settings.

Material changes to this data-handling model must be documented here and called
out in release notes before publication.
